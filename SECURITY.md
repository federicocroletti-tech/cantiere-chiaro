# Segnalazioni di sicurezza e privacy

Non pubblicare credenziali, vulnerabilità non corrette, dati personali o dettagli di casi concreti in issue o pull request pubbliche.

Se GitHub Private Vulnerability Reporting è attivo per il repository, usarlo per segnalazioni di sicurezza. Altrimenti contattare privatamente il maintainer tramite i canali GitHub disponibili, indicando solo le informazioni necessarie per la verifica. Non allegare dati personali o documenti reali.

Per una segnalazione relativa alla privacy, descrivere il tipo di dato e il percorso interessato senza riprodurre il valore. Le segnalazioni saranno esaminate e, se necessario, il contenuto interessato potrà essere temporaneamente sospeso mentre si verifica il problema.

Non è pubblicato un impegno sui tempi di risposta; le segnalazioni credibili con rischio concreto ricevono priorità.
