# Stato di verifica dei contenuti

**Ultimo controllo dell'inventario iniziale:** 2026-10-30.

I documenti recuperati dal repository preesistente non hanno un registro di fonti completo o una data documentata di revisione professionale. Sono pubblicati come materiali iniziali **DA VERIFICARE**, non come procedure certificate o pareri.

## Stati

- **BOZZA:** incompleto; non usare come istruzione.
- **IN REVISIONE:** fonti o contenuto in verifica.
- **DA VERIFICARE:** non esiste evidenza sufficiente di controllo corrente.
- **VERIFICATO alla data indicata:** verifiche documentate alla data dichiarata; non garantisce applicabilità al caso.
- **DA AGGIORNARE:** fonte o regola può essere cambiata.
- **RITIRATO:** non utilizzare.

Ogni procedura futura dovrebbe indicare fonte, data di consultazione, territorio, revisore e prossimo riesame. Uno stato non equivale a una garanzia di correttezza o a una consulenza professionale.
