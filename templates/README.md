# Modelli orientativi

I modelli servono a organizzare informazioni e richieste; non sono formulari ufficiali, non sono personalizzati e non garantiscono un esito. Verificare contenuti e destinatario prima dell'uso.

Usare copie locali con dati sintetici o strettamente necessari. Non caricare fascicoli, documenti reali, firme, fatture, fotografie o comunicazioni personali in issue e pull request pubbliche.
